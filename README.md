I coded this virtual amp in C++, converted it to a .vst3 file to be used in DAW's, and finally converted that .vst3 file into a .nam file to be uploaded to digital guitar pedals like 
the Strich Pipe Tones. I hope other people can use it to write and play music more efficiently!

The .exe can be used to hear playback from an AIO of your choosing, though there will be significant delay. The .vst3 can be imported into a DAW directly. The "New Project" contains 
the files "PluginProcessor" and "PluginEditor", which can be manipulated in VSCode to change the reverb and gain amounts. Inside "Neural Amps" you'll find the .nam file to upload
to your digital guitar pedal.
